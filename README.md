# Alessandro en Asia — IEEE CASE 2026

Sitio web de una sola página que presenta el viaje de Alessandro a **IEEE CASE 2026** (Shenyang, China), con una escala de un día en Seúl, Corea. Construido para mostrarle el recorrido a la familia de forma visual y narrativa.

## Contenido

- Mapa animado de la ruta: Puebla → CDMX → Seúl → Shenyang → Incheon → CDMX → Puebla
- Timeline visual del día en Seúl (15 de agosto)
- Presentación del paper #599, nominado a Best Student Paper en IEEE CASE 2026
- Resumen financiero del viaje (reembolsos, cobertura institucional, costo neto)

## Ver el sitio

Abre `viaje.html` (o `index.html`) directamente en cualquier navegador — no requiere servidor ni dependencias locales. Las fuentes son de Google Fonts y los íconos de Font Awesome, cargados por CDN; las imágenes provienen de Wikimedia Commons.

## Stack

HTML + CSS + JavaScript vainilla, en un solo archivo.
